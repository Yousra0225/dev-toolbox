# ⌨️ Raccourcis clavier essentiels

## 🐚 Raccourcis du Terminal (Bash/Zsh)
Maîtriser ces raccourcis permet de gagner un temps précieux :

- `Ctrl + L` : Efface l'écran (équivalent à `clear`).
- `Ctrl + C` : Interrompt le processus en cours.
- `Ctrl + D` : Ferme le terminal ou déconnecte la session.
- `Ctrl + A` : Déplace le curseur au début de la ligne.
- `Ctrl + E` : Déplace le curseur à la fin de la ligne.
- `Ctrl + U` : Efface tout ce qui est à gauche du curseur.
- `Ctrl + K` : Efface tout ce qui est à droite du curseur.
- `Ctrl + R` : Recherche dans l'historique des commandes.
- `Tab` : Auto-complétion des commandes et des chemins de fichiers.

## 🖥️ Raccourcis du Système (Général Linux)
- `Alt + Tab` : Alterne entre les fenêtres.
- `Super (Touche Windows) + T` : Ouvre un nouveau terminal (sur beaucoup de distros).
- `Ctrl + Alt + T` : Raccourci standard pour ouvrir le terminal.
- `Super + Flèches` : Gère le placement des fenêtres (ancrage).

## 📝 Dans l'éditeur Nano / Vim (Bases)
- **Nano** : `Ctrl + O` (Enregistrer), `Ctrl + X` (Quitter).
- **Vim** : `:w` (Enregistrer), `:q` (Quitter), `:wq` (Enregistrer et quitter), `i` (Mode insertion).
