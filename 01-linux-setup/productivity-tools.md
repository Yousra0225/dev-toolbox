# 🚀 Outils de productivité

## 🔍 Lanceurs d'applications
Alternative au menu classique pour lancer des apps ou chercher des fichiers instantanément :
- **Albert** : Très puissant pour Linux, inspiré d'Alfred (macOS).
- **Rofi** : Minimaliste et très personnalisable.
- **Ulauncher** : Moderne, supporte de nombreuses extensions (Python).

## 🗄️ Multiplexeurs de terminaux
Pour gérer plusieurs sessions dans une seule fenêtre :
- **Tmux** : L'outil de référence. Permet de détacher des sessions et d'y revenir plus tard (très utile sur serveurs distants).
- **Zellij** : Une alternative moderne à Tmux, écrite en Rust, plus intuitive.

## 📋 Gestionnaires de presse-papiers
Garder un historique de ce que vous avez copié :
- **CopyQ** : Très complet avec gestion d'onglets et de scripts.
- **Greenclip** : Excellent pour s'intégrer avec Rofi.

## 🛠️ Autres utilitaires indispensables
- **htop / btop** : Surveillance des ressources système.
- **tldr** : Versions simplifiées des pages de manuel (`man`).
- **ncdu** : Analyse de l'occupation de l'espace disque.
- **fzf** : Recherche floue (fuzzy finder) pour fichiers et historique.
