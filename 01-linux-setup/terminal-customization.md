# 🖥️ Choix et personnalisation du terminal

## 🏁 Pourquoi personnaliser son terminal ?
Le terminal est l'outil principal du développeur sous Linux. Un terminal bien configuré améliore la lisibilité, la rapidité et le confort de travail.

## 📥 Les émulateurs de terminal populaires
Voici quelques excellents choix selon vos besoins :

- **Tilix** : Terminal multiplexeur (permet de diviser la fenêtre en plusieurs volets).
- **Alacritty** : Très rapide, utilise l'accélération GPU.
- **Kitty** : Performant, supporte les images et les scripts.
- **Gnome Terminal** : Simple, stable et préinstallé sur Ubuntu.

## 🎨 Personnalisation visuelle

### Les polices (Fonts)
Pour afficher des icônes (Git, OS, dossier), il est recommandé d'utiliser des **Nerd Fonts**.
- [Nerd Fonts Downloads](https://www.nerdfonts.com/font-downloads) (Exemple : *FiraCode Nerd Font*, *MesloLGS NF*).

### Thèmes de couleurs
- **Solarized** : Un classique reposant pour les yeux.
- **Dracula** : Un thème sombre très populaire.
- **Gruvbox** : Un style rétro avec des couleurs chaudes.

## 🛠️ Outils complémentaires
- **Oh My Zsh** : Pour gérer la configuration de Zsh (voir la section Shell).
- **Starship** : Un prompt universel (marche sur Bash, Zsh, Fish) ultra rapide et personnalisable.
