# 🐙 GitHub : issues, projects & wiki

## 🐛 Issues (Tickets)
Les **Issues** servent à signaler des bugs, proposer des fonctionnalités ou poser des questions.

- **Labels** : Pour catégoriser (`bug`, `enhancement`, `help wanted`).
- **Assignees** : Pour savoir qui travaille sur le ticket.
- **Milestones** : Pour lier des tickets à une version spécifique (ex: v1.0).

## 📊 Projects
GitHub Projects est un outil de gestion de projet type **Kanban** (colonnes : To Do, In Progress, Done).
Il permet de visualiser l'avancement global du dépôt en y glissant les Issues et les Pull Requests.

## 📖 Wiki
Le **Wiki** est une section dédiée à la documentation longue qui ne tient pas forcément dans un seul fichier `README.md`. C'est l'endroit idéal pour :
- Les guides d'architecture.
- Les FAQ.
- Les tutoriels détaillés pour les nouveaux arrivants.
