# 📝 Bases du Markdown

## 💡 Qu'est-ce que le Markdown ?
Le Markdown est un langage de balisage léger qui permet de formater du texte facilement. Il est très utilisé pour la documentation (comme ce guide !), les fichiers `README.md` sur GitHub, et les prises de notes.

## 🏗️ Syntaxe de base

### Titres
```markdown
# Titre H1
## Titre H2
### Titre H3
```

### Style de texte
- **Gras** : `**texte**`
- *Italique* : `*texte*`
- ~~Barré~~ : `~~texte~~`

### Listes
- Liste à puces : `-` ou `*`
- Liste ordonnée : `1.`, `2.`, `3.`

### Liens et Images
- Lien : `[Texte du lien](https://google.com)`
- Image : `![Description](image.png)`

### Code
- Code en ligne : `` `commande` ``
- Bloc de code :
    ```bash
    # Exemple de bloc
    echo "Hello World"
    ```

### Citations
> Ceci est une citation.

### Tableaux

| --------- | --------- |
